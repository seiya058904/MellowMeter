MellowMeter - Windows x64 portable edition

Extract the complete ZIP folder, then open MellowMeter.exe.
The .NET 8 runtime is included. Keep all files in this folder together.
Basic CPU, memory and network monitoring needs no administrator access or extra driver.
The executable is unsigned. Windows 10/11 x64 is targeted; local testing used Windows 11.

Right-click the desktop panel or taskbar strip for settings, themes and history.
Double-click the floating strip to switch its layout.
Settings, traffic and hardware history are kept in %LOCALAPPDATA%\MellowMeter.
Startup at sign-in is optional and off by default. Exit from the tray menu before replacing files.

Version 0.2: 14 themes, including Glass Light and Glass Dark. Existing profiles keep their theme.
Glass effects follow Windows transparency, high contrast and battery saver preferences.
Windows 11 build 22621+ can use Mica in the settings sidebar. Floating/taskbar windows
use a lightweight drawn material to preserve their transparency and click-through behavior.
Turn off Glass effects in Settings > Main Panel for solid surfaces.
The first settings migration saves settings.pre-v0.2.json in the data directory.
Pump/case fan metrics, manual fan selection/calibration and dormant plugin/web/FPS/update
modules are retired. CPU/GPU fans and automatic ranges remain available.
